## 🌐 AI 投资潮能惠及整个 Web 吗？

**来源**: Jim Nielsen's Blog | **时间**: 2026-07-27 19:00

Jason Grigsby 引用 Safari 团队观点：AI Agent 本质上是辅助技术，应当像用户一样操作网站，不应被特殊对待。文章主张 Agent 应使用现有的 Web API 和语义化标记，而非获得专属接口；平台的缺口应该为所有人补齐。换言之——让 AI 投资的浪潮抬高所有船只，而不是给 AI 开后门。有趣的是，文章引用了 Web 标准的"优先级顺位"：用户需求 > 开发者需求 > 实现者需求 > 规范编写者需求 > Agent 需求。

🔗 https://blog.jim-nielsen.com/2026/tide-lifts-all-boats/
