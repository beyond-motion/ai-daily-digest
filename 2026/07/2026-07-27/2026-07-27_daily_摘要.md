**时间**: 2026-07-26 19:30  
**链接**: https://simonwillison.net/2026/Jul/26/relay-market/

Matt Lenhard 深入调查了一个围绕 LLM API key 池化转售的灰色市场，该现象主要出现在中国。转售商通过开源代理软件（one-api 及其分支 new-api），将来自多个渠道的 API key 池化，以显著折扣价向下游用户提供 LLM 访问。

** key 的来源包括**：
- 滥用免费试用额度
- 通过未受保护的支持机器人代理请求
- 盗刷信用卡或拒付攻击

**买家动机**：获取廉价 token、绕过地理限制、收集数据用于模型蒸馏。

Simon 评论道：这让他在公开暴露 LLM 驱动的应用时更加谨慎——现在已经有一整个生态可以从发现新的未保护端点中获利。他呼吁 LLM 厂商提供更严格的 API key 消费上限（如达到美元阈值后自动停止）。

## 4. 🖥️ ARCNET 的兴衰：比以太网更早的局域网标准

**来源**: The Silicon Underground · **作者**: Dave Farquhar  
**时间**: 2026-07-26 11:00  
**链接**: https://dfarq.homeip.net/what-happened-to-arcnet/

ARCNET（Attached Resource Computer NETwork）由 Datapoint 公司于 1977 年推出，是第一个商用的局域网标准，比以太网（1973 年发明，1980 年商用）和 Token Ring 都早。

**核心特点**：
- 采用令牌传递机制（类似 Token Ring），无碰撞问题
- 支持 2.5 Mbps（速度来自当时硬盘的传输速率）
- 比以太网卡便宜 30-60%
- 支持总线、星型和分布式星型拓扑

**为何败给以太网**：尽管在早期 PC（10 MHz 以下）上 ARCNET 和 10 Mbps 以太网实际速度相当（因为以太网碰撞开销大），但随着处理器速度提升（386/25MHz 以上），以太网的优势开始显现。更关键的是 ARCNET 升级到 20 Mbps 的版本延迟推出，标准化的滞后使其失去市场。
