## 🌐 Web / 开发

### A simple "copy this code" button in JavaScript
- **Source**: Terence Eden's Blog
- **Author**: @edent
- **Date**: 2026-08-29 11:34
- **Link**: https://shkspr.mobi/blog/2026/08/a-simple-copy-this-code-button-in-javascript/

edent 博客里所有代码块旁边都有一个 "⧉" 复制按钮。HTML + JS 实现简洁到极致：

```html
<button onclick="navigator.clipboard.writeText(
    this.parentNode.getElementsByTagName('code')[0].textContent
);" title="Copy code">⧉</button>
```

**注意**：`navigator.clipboard.writeText` 必须由用户交互触发，security context 一般要 HTTPS。这正是为何大多数静态站改用 `document.execCommand('copy')` 兼容兜底。
