## 1. 🔥 Gary Marcus 反驳 Astra 炒作：数学突破 ≠ AGI

**来源**: Marcus on AI · **作者**: Gary Marcus  
**时间**: 2026-08-02 21:25  
**链接**: https://garymarcus.substack.com/p/openais-amazing-but-vastly-oversold

继昨日 OpenAI 宣布 Astra 模型攻克十大数学难题后，Gary Marcus 发表了一篇措辞严厉的反驳文章，指出当前的狂欢存在一个经典的逻辑谬误——**合成谬误（Fallacy of Composition）**：在某个领域的出色表现，不等于在所有领域都出色。

**核心论点**：

1. **营销而非科学**：OpenAI 发布的 249 页论文中没有一页说明模型如何工作、证明如何验证、人类扮演了什么角色。Ernie Davis 指出，我们不知道他们尝试了多少个猜想才命中 10 个，也不知道背后科学家团队的人力成本。
2. **数学的特殊性**：数学之所以是 AI 的最佳战场，是因为它支持外部工具验证和大规模廉价合成数据——这两个条件在现实世界问题中并不成立。"你可以生成无限多的数学事实，但你无法模拟开放世界。"
3. **证明质量存疑**：数学家 Henry Yuen 指出 Astra 的证明写作充满 ChatGPT 风格——冗长铺设"样板"步骤，却在关键跳步处轻描淡写。
4. **前车之鉴**：IBM Watson 赢了 Jeopardy 后说要攻克癌症，最终失败了。一个领域的成功不保证全面成功。

Marcus 总结道："Astra 令人印象深刻，但任何期待魔法的人大概率会失望。"

## 2. 💬 Boris Cherny 谈构建 Claude Code：删除 80% 系统提示词、给模型更难的任务

**来源**: YC Root Access (via Daring Fireball) · **作者**: Boris Cherny  
**时间**: 2026-08-02 21:01  
**链接**: https://www.ycrootaccess.com/p/boris-cherny-building-claude-code

Anthropic Claude Code 负责人 Boris Cherny 在 YC Startup School 2026 上接受采访，分享了大量产品构建洞察：

**Opus 5 的新能力**：
- 模型可以连续运行数天、数周甚至数月而不需要外部脚手架
- **Prompt 注入问题基本解决**：结合三年对齐研究、基于 Crisola 机制可解释性的神经元级分类器和 auto mode 分类器三层防护，"我们已无法演示 prompt 注入"
- Arc AGI 3 得分从个位数跳到 30%

**删除 80% 系统提示词**：Opus 5 足够聪明，大量原本纠正模型行为的指令已不必要。团队通过"消融"（ablation）逐行删除提示词来评估每行的影响。甚至有一个隐藏的 `simple=1` 环境变量可以删除所有提示词——发现模型在没有提示时反而更聪明。

**"产品悬垂"（Product Overhang）**：模型已具备的能力 vs 产品实际利用的能力之间存在巨大鸿沟。Claude Code 的诞生就是因为 Sonnet 3.5 时代没有产品敢于让模型一次写整个文件。

**经典案例**：
- Bun 运行时团队用 Claude Code 将整个代码库从 Zig 重写为 Rust，一个 dynamic workflow 运行 11 天完成，已在生产环境使用
- Cherny 自己用 Claude Tag（Slack 中的 Claude）指挥 macOS 虚拟机，将 Electron 版 Claude 桌面应用重写为 Swift 原生应用

**核心建议**："给模型比你认为它能力上限更难一点的任务。描述任务、护栏和退出条件，然后让它去做。验证是你能做的最重要的事。"

## 3. 📱 Agent Fone：一部会自己写 App 的手机

**来源**: Daring Fireball (赞助) · **作者**: John Gruber  
**时间**: 2026-08-02 21:02  
**链接**: https://fail.xyz/phone/

Agent Fone 是一款理念激进的新智能手机：不只是预装 AI 助手，而是整个概念就是"让手机自己为你创建定制软件"。描述你的想法，回答几个问题，App 或 Widget 就出现在主屏幕上。

**核心理念**：
- 过去 20 年智能手机是"别人软件的自动售货机"，你要适应软件
- Agent Fone 翻转这个关系：手机理解你的生活（联系人、聊天、收据、照片），主动把混乱变成杠杆
- 后台代理可以监控、创建、跟进、提醒——"你从未雇佣的前台、媒体团队、记账员"
- 所有学到的东西（你的模式、品味、客户）都是你拥有的记忆：可见、可编辑、可迁移

目前正在寻找 50 个首批用户/小团队。

## 4. 🔧 condense-json 1.0 发布：压缩 JSON 中的重复字符串

**来源**: Simon Willison's Weblog · **作者**: Simon Willison  
**时间**: 2026-08-02 22:19  
**链接**: https://simonwillison.net/2026/Aug/2/condense-json/#atom-everything

Simon Willison 发布了 condense-json 1.0——一个一年半的小库终于"勇敢地"发布大版本。

**原理**：扫描 JSON 中的字符串和子串，对照 replacements 字典，将匹配部分替换为 `{"$r": [...]}` 语法。反向操作 `uncondense_json()` 可恢复原文。

**用途**：主要用于压缩 LLM 生成的 SQLite 日志中的重复数据。一个 1.5 年的成熟工具，经过多次迭代后发布 1.0。

## 5. 📐 John D. Cook 数学二连：全纯函数与累积和估计

**来源**: johndcook.com · **作者**: John D. Cook  
**时间**: 2026-08-02  
**链接**: https://www.johndcook.com/blog/2026/08/02/holonomic-functions/

两篇数学短文延续昨日的话题：

- **Holonomic functions**：昨日提到"多项式系数的二阶线性微分方程"在数学物理中频繁出现。更一般地，全纯函数（holonomic functions）定义为任意阶线性微分方程+多项式系数的解。大多数特殊函数都属于此类。
- **Estimating a cumulative sum**：无标记有根树计数序列 t(n) 的累积和 c(n)——同时也是 n 步 Runge-Kutta 方法的约束数量。作者探讨了如何估计这个累积和的渐进行为。
