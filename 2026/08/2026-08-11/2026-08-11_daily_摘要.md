## 1. No, local models will not win
- **来源**: seangoedecke.com
- **作者**: Sean Goedecke
- **链接**: https://seangoedecke.com/local-models-will-not-win/
- **要点**: 
  - 每当新的开源权重模型发布，就有人说本地模型是未来。作者认为这判断注定失败——绝大多数推理仍会在数据中心进行。
  - 本地模型"太弱"：当前所有前沿模型（无论开源闭源）都太大，只能在数据中心 GPU 集群上跑。
  - "小模型每年都在变强"也是真相，但用户的**显性偏好**始终是用最强模型。AI 没停在 GPT-4；如果真停了，我们也能围绕 GPT-4 造工具，但今天谁还用 GPT-4？
  - 当 LLM 越来越强，用户的期望也跟着涨——agentic 系统要能独立解决更多问题。能力越强、阈值越高，人们永远会选"少让人抓狂"的那个，也就是更大的模型。
  - 结论：本地模型不会赢，赢的是**"更好、更便宜的闭源模型"** + **"在数据中心按 token 卖给消费者"**。

## 2. Introducing Muse Glimmer
- **来源**: Simon Willison's Weblog
- **作者**: Simon Willison
- **链接**: https://simonwillison.net/2026/Aug/10/introducing-muse-glimmer/#atom-everything
- **要点**:
  - Meta 重返开源权重战场——**Muse Glimmer** 是一个全新的 **30B 模型**，采用干净的 **Apache 2.0** 协议（比 Llama 老协议清爽多了）。
  - 三个主打能力：
    - **End-to-End Agentic Task Completion**：在 DeepSearch QA、MCP-Atlas、τ-Bench、SWE-Bench 上表现强。
    - **Reliable Tool Use**：长流程下保持 schema 精确。
    - **Multi-Step Reasoning**：在复杂长程任务里保持连贯计划。
  - Simon 用了 LM Studio 的 18.16GB 版本跑了鹈鹕图，也用 `llm-coding-agent` 在全新 Datasette 仓库上跑了 "how does auth work?"，能正常调用工具走完整个代码库探索。
  - 这个尺寸正好——32GB+ 内存的机器（他 128GB）跑得动，还能同时干别的。

## 3. Open-source is NOT the same as open-weight
- **来源**: Gary Marcus 的 Substack
- **作者**: Gary Marcus
- **链接**: https://garymarcus.substack.com/p/open-source-is-not-the-same-as-open
- **要点**:
  - 《纽约时报》把 open-weight 与 open-source 混为一谈，Gary Marcus 认为这是个严重错误。
  - 区别很关键：open-weight 只开放权重，不开放训练数据、训练代码、训练方法；open-source 是完整的可复现性。
  - 把 open-weight 当成"开放 AI"会误导监管、公众和开发者。

## 4. The NYT and WSJ on Apple, China, and the RAM Crisis
- **来源**: Daring Fireball 转载 NYT / WSJ
- **作者**: Kalley Huang / Ana Swanson (NYT), Raffaele Huang / Rolfe Winkler (WSJ)
- **链接**: https://www.nytimes.com/2026/08/10/technology/memory-chip-shortage-ai.html
- **要点**:
  - Apple 因内存芯片短缺导致近期涨价，正在联合其他消费电子公司游说**放宽对中国芯片的采购限制**。
  - 2022 年 Apple 曾与长江存储（YMTC）谈判，最后在美国议员压力下告吹。
  - WSJ 跟进：Apple 正在测试**中国 CXMT** 的内存芯片，覆盖 iPhone 和 MacBook 产品线；目标是先用在**在中国销售的设备**，并寻求白宫批准。
  - 背景：AI 浪潮导致全球内存吃紧，Apple 想两头下注。
