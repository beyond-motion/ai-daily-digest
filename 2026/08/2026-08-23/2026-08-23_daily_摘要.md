### 3. llm 0.33 — Simon Willison's Weblog

- **作者**：Simon Willison
- **发布时间**：2026-08-22 17:01
- **链接**：https://simonwillison.net/2026/Aug/22/llm/

**完整摘要**：
llm 0.33 主要更新：
1. **OpenAI 库升级**：升级到 OpenAI Python 库 3.x，HTTP 客户端依赖从 httpx 切换到 httpx2（#1608, #1631）。昨天已经发了 0.32.1 快速修复
2. **Embedding API key 支持**：`llm embed` 和 `llm embed-multi` 现在接受 `--key` 参数。Python 的 `EmbeddingModel.embed()`, `EmbeddingModel.embed_multi()`, `Collection.embed()`, `Collection.embed_multi()` 方法也支持 `key=`，将每调用的 key 传递给 embedding 插件而不改变共享模型状态。现有通过兼容性 fallback 读取 `self.key` 的插件继续工作。感谢 ChrisJr404（#757, #1620）
3. **模板组合**：`llm prompt -t/--template` 现在可以重复以按顺序组合模板。这允许将一个模板的模型配置和选项与另一个模板的 prompt 一起使用。解锁一个新模式：可以创建将模型与一组默认选项打包在一起的模板：
   ```
   llm -m gpt-5.6-luna -o reasoning_effort high --save lhigh
   llm "Generate an SVG of a pelican riding a bicycle" --save pelican
   # 组合并运行模板
   llm -t lhigh -t pelican
   ```
4. **Reasoning summary**：支持 reasoning 的 Responses API 模型现在支持 `reasoning_summary` 选项，取值 `auto`、`concise`、`detailed`。可与 `llm openai endpoint --responses` 一起使用（#1600）。这对使用模仿 OpenAI Responses API 的不同模型特别有用
