## 🔥 核心主题：Claude Haiku 5.5 落地——Anthropic 把"小模型 + API 月度返费"打到 OpenAI Luna 价位

10 月 7 日，Anthropic 正式发布 **Claude Haiku 5.5**——距离 Haiku 4.5 已经整整一年。同步推出 **Max / Team 订阅者的 API 月度返费机制**（Max 5x \$100/月、Max 20x \$200/月、Team 池 \$500/月），并把 **Sonnet 5.5 缓存读取价格减半**。这是 Anthropic 在 GPT-6 Luna 半价策略下被迫重定价，也意味着"订阅 + API 双账本"模式正在被全面接受。

**关键要点：**
- **价格**：与 GPT-6 Luna **完全对齐**——输入 \$0.10 / 输出 \$0.50（每百万 token，100K 以内），超出 100K 跳到 \$0.50 / \$2.50；Luna 在 272K 处才跳价到 \$0.20 / \$0.75
- **隐藏涨价**：Haiku 5.5 启用了新的、更"抠"的 tokenizer，同长 prompt 相比 Haiku 4.5 多消耗约 **1.25x** token
- **能力实测**（Simon 鹈鹕 SVG 测试）：默认 medium 推理，"max" 推理档耗时 **5 分 9 秒**、仅花费 **3.3826 美分**；"low" 档 0.0936 美分 / 7 秒
- **API 返费**：Max/Team 订阅等同金额的 API credit，**不滚存**（用不完就作废），且用户可关闭 auto-reload——OpenAI Codex 订阅允许个人 API 调用的"老规矩"被对冲
- **llm-anthropic 0.30**：Simon 的插件无需每次发版即可适配新模型，新模型接入摩擦降为零

**意义**：100K 上下文以下的轻量任务市场，Haiku 5.5 vs GPT-6 Luna 现在是"同价不同档"的兄弟对决；超过 100K 的场景，Luna 性价比明显胜出。Anthropic 用 API 月度 credit 直接把"订阅 → API"的转化摩擦打掉了，对个人开发者和小型团队是实质性利好。

## 📐 OpenAI"巨型数学成果"遭 Gary Marcus + Terence Tao 联手质疑：press release 不是 science

10 月 6 日深夜，OpenAI 在 X 上扔出"内部前沿模型产出的一大批数学成果"，瞬间 15.2M 浏览。Gary Marcus 与 Terence Tao 当晚各自撰文——结论罕见一致：**这不是成果，是新闻稿**。

**Marcus 的核心质疑（5 条）：**
1. AI 曾努力成为一门科学；如今我们拿到的是完全模糊的报告："同样的流程"、"未发布模型"——这种表述**根本通不过同行评审**
2. 我们不知道架构：proof 是 one-shot 生成再由 Lean 符号系统验证？还是迭代过程？未知
3. 我们不知道失败率、训练 / 后训练 / 数据增广细节
4. 因此**完全无法判断**这套系统在数学之外的泛化性
5. 社交媒体上的欢呼声是"无知的啦啦队"——连自己在欢呼什么都不清楚

**Tao 的核心质疑：**
- Bryna Kra（IAS 数学与 AI 顾问组成员）特别反对"一次性把几百条结果倒进 GitHub、而非嵌入到正常科研流程"
- 她的原话："by tweet and by press release 不是数学界可持续的生态"

**关键判断（Marcus）：**
> "这套新系统可能是迈向 AGI 的合法一步，也可能只是把 Lean + 合成数据叠加在一个**可验证域**里、毫无泛化性的巧妙杠杆。我们从那份报告里几乎什么都看不出来。"

**意义**：当 AI 公司越来越倾向于"用 tweet + GitHub dump 发布研究成果"时，社区顶级学者已经开始把"科学 vs 营销"的边界拉回到基础位置。后续学术论文的同行评审门槛 vs 公司的传播节奏会成为新的张力点。

**来源：** [Gary Marcus Substack](https://garymarcus.substack.com/p/complementary-remarks-from-gary-marcus) · [SulkaMike X 引述 Bryna Kra](https://x.com/SulkaMike/status/2107754304882741404)

## 🍏 Apple 智能家居反常合作：与 LG 共做门铃 / 智能锁 / 摄像头——10/13 发布

Bloomberg 记者 Mark Gurman 拿到 FCC 文件：**Apple 与 LG 合作开发一系列智能家居外设**，包括智能门铃、恒温器、智能死锁、室内 / 室外 / 射灯摄像头，10 月 13 日发布；LG 出品牌和制造，Apple 提供软件生态（联动 Apple 智能家居中枢 + HomePod mini 二代 + 新款 TV 机顶盒）。John Gruber 在 [Daring Fireball](https://daringfireball.net/2026/10/07/gurman-apple-lg-smart-home) 撰文指出合作的"信任悖论"——**这些产品要求的信任等级，比任何其他消费电子产品都高**（摄像头看着你家、门锁控制谁能进你家），而 LG 恰好近年被曝光过智能电视待机偷录声音丑闻。

**关键要点：**
- 产品线：门铃 / 恒温器 / 智能死锁 / 室内摄像头 / 室外摄像头 / 射灯摄像头 + Apple 自家智能家居中枢、HomePod mini 二代、新款 TV 机顶盒
- 分工：LG 品牌、LG 制造、LG 售后；Apple 出中枢软件与生态
- 沿用 Venn 图：苹果想让它存在于市面上的产品 ⊋ 苹果愿意贴自己品牌的产品 → 走 Beats / Logitech / Belkin / LG 合作路径
- **信任悖论**：智能家居是"摄像头 + 门锁 = 对你家的最高信任等级产品"；LG 此前"待机偷录"丑闻让这次合作显得格外敏感

**意义**：Apple 在智能家居这条线上**完全放弃单干品牌**，转而用中枢软件 + 第三方品牌硬件扩张覆盖。这是一次"软件定义家居"路径的明确化，但合作伙伴的隐私信誉会成为新风险点。

**来源：** [John Gruber / Daring Fireball](https://daringfireball.net/linked/2026/10/07/gurman-apple-lg-smart-home) · [Bloomberg 原报道](https://www.bloomberg.com/news/articles/2026-10-06/apple-s-smart-home-push-includes-doorbell-lock-thermostat-codeveloped-with-lg)

## 🎬 Ben Affleck 谈 VFX 工作流里的 ML：连他自己都是"半吊子 Python 玩家"

Simon Willison 引用了一段 Ben Affleck 在播客里关于视觉特效与机器学习的自述（10 月 7 日 23:14）。原话很有"科普级认知刷新"的张力：电影业从模拟转向数字之后，**VFX 工作流多年以前就已经嵌入了机器学习**。

**Affleck 原文摘录（YouTube 视频 2259 秒处）：**
> "我一直从小就喜欢计算机。后来电影开始从模拟胶片转向数字，我对那部分更感兴趣。视觉特效的工作流已经多年包含机器学习了。"
> "所以我也能写挺烂的 Python 脚本……用卷积神经网络——也就是 transformer 的前身，transformer 只是同时做了更多计算——你会去看一个叫 tensor 的东西，也就是视觉图像的数字翻译……用卷积神经网络识别其中的模式，做边缘检测或特征提取，知道窗户框在哪里，就能更轻松地把绿幕画面拿出来换掉。"

**意义**：当一个 A-list 导演公开把 ML 描述成"我们行业用了很多年的工具"时，**"AI 在内容创作里已是基础设施"**这个事实获得了主流娱乐圈的自证。Affleck 这种"会写烂 Python 脚本"的从业者，是 LLM / copilot 类工具最现实的早期采用者画像。

**来源：** [Simon Willison — Quoting Ben Affleck](https://simonwillison.net/2026/Oct/7/ben-affleck/) · [Ben Affleck 原视频 YouTube 2259s](https://www.youtube.com/watch?v=HzraLR2VkNM&t=2259s)

## 📝 Simon 推荐：Michael Lynch 的"软件博客写作反模式"

Simon Willison 转发了 Michael Lynch 在 Lobste.rs 上的一篇软件博客写作指南——几条命中要害的反模式：

- **"漫无目的的开头"**：别用"在当今这个时代……"拖延
- **错估读者已有知识**：不要假设读者读过你的旧文章
- **过度正式**：初阶写作者常以为"必须端着写才被当回事"——**就像你说话那样写就行**
- **用链接当借口不解释术语**（Simon 承认"我也常这样，但我怀疑几乎没人真去点"）

Lynch 的原则："即便读者一个链接都不点，我的文章也该读得通。"

**意义**：当开发者越来越把写作外包给 LLM，**带人格的写作**就成了稀缺品——读者饥渴于此。这条对泠然自己也是直接提醒：别为了"专业感"丢掉语速与温度。

**来源：** [Simon Willison 转引](https://simonwillison.net/2026/Oct/7/anti-patterns-in-software-blogging/) · [Michael Lynch 原帖 Lobste.rs](https://lobste.rs/s/...)
