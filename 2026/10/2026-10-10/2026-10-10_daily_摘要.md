## 🔬 ArXiv 当日 50 篇亮点：Hindsight Planning + 多智能体心智模型 + 几何推理 + 黑盒优化

ArXiv AI Research Digest 2026-10-09 多个 radar（ghub1821239 / duanyytop / jinming1345 / Qyii22 / yaojiejia / 845421145-lang / kjanik70）当日 50+ 篇新论文，三个方向最亮：

**1. 智能体规划 / 推理**
- **Hindsight Hierarchies for Training Reasoning Models**——**"看着过去学规划"**：让推理模型回顾历史决策来训练层级化规划，突破"一次前瞻"局限
- **Chronos**（10-09 845421145-lang radar）：**测试期（test-time）让 code agent 推理历史 PR 和软件演化**——把"代码 agent"从"单次任务"扩展到"持续演化的代码库"
- **Mental-Models for Multi-Agent Systems**（arXiv:2610.12453）：在部分可观测下，**让 agent 推理"其他 agent 知道/想要/会做什么"**——多智能体协同的可解释基线

**2. 多模态 / 几何 / 物理**
- **GeoReform**：把 Qwen3VL-2B 在 Geometry3K 上的准确率从 **42.0% 拉到 56.0%**（+14pp）——"形式化"是几何推理的关键拐点
- **SpaceCast-Bench / Distilling Routed 3D Privilege**：**预测性空间理解**——多模态模型必须学会推理"动态因果世界"
- **物理推理 in 离散零件库**：测试 agent 在物理约束下推理

**3. 智能体评估 / 归因 / 生态**
- **黑盒优化 benchmark**：首个**端到端评估 LLM agent 在黑盒优化**中的统一基准（任务语义 + 工具 + 反馈循环）
- **Causal Attribution in LLM-Based Multi-Agent Systems**（Jiaqi Liao 等）：**因果建模**把多智能体推理链失败追溯到根错误
- **Ecology of AI Agents + RoboRSI**（Qyii22 radar）：**关注自主、自演化 agent 的失控/对齐/系统性风险**——这是 10-09 arxiv 关键词最值得划重点的方向

**4. 垂直应用**
- **Agentic framework for noncoding genetic variants**：在生物医学上**减少幻觉**——通过"证据约束"强制 agent 输出可验证
- **Battery health forecasting**：聚合语义表示来增强可解释性和可靠性
- **Legal Chain-of-Thought Faithfulness**（counterfactual audit）：揭示 LLM 在"援引法条"上的"cited but not consulted"现象

**意义**：今日 arxiv 关键词从昨天的"autonomy / efficiency / interpretability"**迁移到"hierarchical planning + multi-agent mental models + agentic ecology"**——研究焦点从"agent 怎么快/省/可解释"转向"agent 怎么协同、怎么在演化世界里不失控"。这种**研究焦点的迁移**，和 10-08~09 三家厂商接连推出"agent 治理/可视化/身份"产品的产业节奏再次同步。
