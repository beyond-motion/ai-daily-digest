### 1. OpenAI 发布 GPT-6 Astra：CAD 几何 95.9%，API 价格腰斩

**关键基准 BenchCAD（多视图 3D 重建生成 CAD 代码）**：

### 6. ai-boost/awesome-harness-engineering：Agent 工程的 awesome 列表诞生

**来源**：[github.com/ai-boost/awesome-harness-engineering](https://github.com/ai-boost/awesome-harness-engineering)（1 天前）

这是一个全新的 GitHub awesome 列表，覆盖 Agent harness 工程的所有关键主题：
- tools / patterns / evals
- memory / MCP / permissions
- observability / orchestration

**核心心智模型**（来自 Birgitta Böckeler 2026 年 4 月的演讲）：
> Harness = **feedforward guides（前馈引导）** + **feedback sensors（反馈传感）**，在输出到达人类眼前之前自我纠错

**两类控制**：
- 计算型控制（linters, tests）—— 确定性
- 推理型控制（LLM-as-judge）—— 不确定性

**核心论点**："harnessability"（可被 harness 包裹的程度）应成为**技术和架构决策的一等标准**。

**3 个 Agent Harness 设计模式**：
1. **构建在 Claude（模型）已知的工具上**——减少训练摩擦
2. **随能力提升移除 harness 假设**——不要 over-engineer
3. **谨慎设置 UX / cost / safety 边界**——明确 trade-off

**为什么重要**：当 awesome 列表开始专门收录"harness engineering"主题，意味着行业共识已经形成——**Agent 工程的瓶颈不在模型，而在 harness**。这和 Pebblous 评测互相印证。
