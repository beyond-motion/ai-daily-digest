### llm-keys-ui 0.1：安全管理 LLM API Key 的本地 UI

Simon Willison 发布 llm-keys-ui 0.1，解决一个具体场景痛点：通过 Codex Remote 在多台机器上运行 AI 编程助手时，偶尔需要向机器注入新的 API Key——但又不想把 Key 直接粘贴进 ChatGPT 应用。

**工作原理：**
```bash
uvx --with llm-keys-ui llm keys-ui --all
```
启动后可在同一局域网或 Tailscale 设备上访问 Web UI，输入新 Key；之后 Codex 可以通过 `llm keys get anthropic` 等命令调用。
