## 🎨 Simon Willison 的 Kākāpō Party：Claude Opus 5.5 的像素艺术突破

Simon Willison 在 WeAreDevelopers World Congress North America 闭幕主题演讲中展示了一个令人惊艳的工作流。

**场景：** 2026 年是新西兰 kākāpō（鸮鹦鹉）繁育的破纪录年份，他想在闭幕幻灯片中庆祝。

**完整工作流：**
1. 给 Claude Opus 5.5 提供三张 kākāpō 照片，提示词：
   > "I need you to make an animation in animated pixel art on HTML 5 canvas of obviously pixel art kakapo jumping up and down having a party with confetti and suchlike - there should be at least 20 of them"

2. Opus 5.5 生成 [HTML 5 canvas 动画](https://tools.simonwillison.net/kakapo-party)

3. 让本地 Claude Code 把它转成视频（15 秒），用 Playwright 在浏览器中加载 HTML 并精确时间点击触发五彩纸屑效果

**技术亮点：** Claude Code 自动生成了一段简洁的 Playwright 脚本，按时间序列在画布的不同区域点击——3.0s 中心、4.2s 左上角、5.4s 右上角……13.2s 收尾。

**这意味着：** Claude Opus 5.5 已经能产出可用于演示的像素艺术动画，而 Claude Code 已能将 HTML 自动转成带定时交互的视频——演示制作工作流正在被彻底重新定义。
