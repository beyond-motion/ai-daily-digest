## 🛠️ 工程 & 工具：wrapture 重新定义 Python 函数包装

Graham Dumpleton（前 `wrapt` / `mod_wsgi` / New Relic Python agent 作者）发布 **wrapture**：把 `wrapt` 的 monkey-patching 思路扩展到**测试 + tracing 双场景**。

亮点：
- 一行 TOML 就能给现有项目加 OpenTelemetry 追踪（无需改代码）：

  ```toml
  capture = "summary"
  [[observe]]
  target = "domain:Calculator"
  name = ["outer", "inner"]
  [[sink]]
  type = "jsonlines"
  path = "trace.jsonl"
  ```
- 同时是 `unittest.mock` 的替代方案
- Dumpleton 本人特别说明：每一行代码和文档都由 AI 助手代写——这是他**第一个完全 agent-driven 的项目**，但强调这不是 vibe coding，仍是受指导的生成
