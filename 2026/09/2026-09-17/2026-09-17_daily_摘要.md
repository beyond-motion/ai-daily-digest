## 🛡️ AI 治理 / 政策：Cory Doctorow 戳破"AI 暂停令"对巨头反而是赢

Cory Doctorow 9 月 16 日的 *Pluralistic* 头条：**"How an AI moratorium can save AI bosses"**。核心论点是 — 假如你不能制造"切换成本"（switching cost），那就**直接消灭竞争**。

他引用之前 *econopocalypse* 帖的数据，说明 hyperscaler 模式在单位经济上根本跑不通，巨额 capex + 负 unit economics + 越新一代亏得越多。再叠加 wheresyoured.at 与 Futurism 揭露的"假账"问题（Anthropic 用 **non-GAAP 私有会计标准**自称盈利，对标 WeWork 套路），"AI 即将盈利"是经不起推敲的承诺。

但 Doctorow 不止于此 —— 他指出 Anthropic 一旦发布重要 Claude 更新，**OpenAI 的最佳 coding 体验几乎瞬间被替代**。这种"无切换成本"恰恰是大模型行业的结构性死穴。于是"AI 暂停"或强监管，对在位者反而是好事：竞争对手被冻住，自己还持续收钱。"AI 暂停"不是为公共利益，是为 AI boss 的资产负债表。

**关键要点：**
- Hyperscaler 模式单位经济为负，财务披露"非 GAAP"几乎等于承认无 GAAP 利润
- 行业没有 switching cost——对手一发新版，你昨夜的所有粘性归零
- "Moratorium"在政治上有迷惑性，但实际上是"卡竞争对手"工具
- Doctorow 把"AI 暂停令"等同于 90 年代 IBM 主导反垄断前的"开放标准延缓"戏码

**来源：** [Pluralistic: How an AI moratorium can save AI bosses (16 Sep 2026)](https://pluralistic.net/2026/09/16/beggar-thy-neighbor/)

## 🔒 安全 / 隐私：Apple Reference Image vs Flock 摄像头漏洞，同一天上演"可验证摄影"两面

两个不同维度但都和"信任"相关的故事撞在 9 月 16 日：

### Apple：iPhone 18 Pro 推出 Apple Reference Image（可验证摄影）

Apple Security Engineering + Camera 团队博客披露了一个新方案：让 iPhone 主摄拍出的照片**在硬件层 + PCC（Private Cloud Compute）** 双重保证下，成为"可被第三方核验、不可伪造"的 reference image。三个核心要求：**语义真实性（sensor 真实捕获）/ 不可篡改 / 隐私保护**（不会把摄影师身份暴露给公众密钥）。**只在 iPhone 18 Pro / 18 Pro Max 的主摄首发、opt-in**。这明显是冲着 C2PA 的"链中任一环被攻破就完蛋"弱点去的——Apple 用 **secure enclave + PCC 可审计云** 替代"metadata trail"思路。

### Flock ALPR 摄像头：跑着 2018 年 6 月的 Android 8.1 + Linux 3.18.71

Micah Lee 通过 DDoSecrets 发布的固件 dump 做了反向工程。Flock（美国主要车牌识别摄像头厂）相机：
- Android patch level = **2018-06-05**，缺近 8 年安全更新
- Linux kernel **3.18.71（2017）**，3.18 系列已于 2019 年 5 月停维护，落后 69 个 patch
- 含 Qualcomm Adreno GPU 提权（CVE-2021-1905）+ IPv6 socket 提权（CVE-2018-9568）等已知可利用漏洞
- Flock 官方回应"请通过 vulnerability disclosure 提交"——hacker 们说这就是"等你"。

**关键要点：**
- Apple 想让"我拍的是真照片"成为可验证事实，反 AI 生成图乱象
- Flock 摄像头（已被警察局/小区广泛部署）实质上是 **9 年未打补丁的 Linux box**——批量化国家级监控基础设施的脆弱性非常具体
- 两个故事放一起看：**iPhone 在抬升"真"的门槛，老旧 ALPR 在践踏"可信"底线**

- [Apple Reference Image: A New Approach for Verified Photography](https://security.apple.com/blog/apple-reference-image/)

## 💼 行业 / 舆论：Altman / Huang / Sanders 三种"信我"姿势，Gary Marcus 一一拆解

Gary Marcus 昨晚在 BBC 节目里被连续播放 Sam Altman / Jensen Huang / Bernie Sanders 三段发言，他说自己差点在电子 green room 里吐了。**这三条代表了"AI 公共话语"的三种主流姿势**，但 Marcus 认为全都站不住：

3. **Sanders："AI 比核武还危险"** —— Marcus 承认 AI 会被滥用做基础设施攻击和诈骗，但用核武死亡数（数亿级）类比 AI 风险**缺量级感**。他建议参照 COVID-19（全球 1900–3600 万死亡）才合理，且全世界 85% 人口会同意**直接关停**。

- Altman 的"trust me"是 **rhetorical asset**（拿到话语杠杆），但内容空
- Huang 的"自律"是 **Pollyanna 立场**，GPT-6 Astra 反例存在
- Sanders 的"核武级威胁"**缺乏量级感**，反而会让真正的（次级）AI 风险被夸张后失焦
- Marcus 立场：他主张 **联邦监管**而不是任何一种企业自律或道德呼吁

## 📚 工程 / 趣味：LLM 写代码集体痴迷"spine"，20 倍的 GitHub PR 异常

Hillel Wayne（"Computer Things"）做了一个 LLM-isM 检测实验：在 GitHub public PR 标题里数 "spine" 词频。**2026 年前 9 个月的 PR 数量已是 2025 全年的 20 倍**，远超 GitHub 整体增长（同期 PR 总数约 1.5x）。他在 TLA+ 形式规约里反复见到这个"spine"——甚至在非 TLA+ 公开项目里。

**其他 LLisM 候选词：**
- **gate** —— 1/300 PR 标题，body 含的话 1/26
- **lane** —— 显著上升（可能与 CPU lanes 有关，未证实）
- **proof** —— 形式化验证热推动
- **truth** —— 显著上升
- **seam** —— 同事提示

他做了一个**清洁版 LLM**反查"ladder"突增 → 答案：boto3 自动升级提示里出现 "ABR package ladders" 这种**机器化文案污染**。说明必须只看 PR 标题而非 body。

**关键要点：**
- "spine" 已成为**可识别的 LLM 写作指纹**——和早期 "delve into"、"tapestry"、"leverage" 同一性质
- 跨多家模型（Claude / Cursor / 多家）共现，说明是**训练数据共性而非单一模型问题**
- 给 reviewer 提供了一个简单 trick：**标题里出现"spine/gate/lane/seam/truth"的 PR，默认怀疑 LLM 参与**

**来源：** [The LLMs yearn for the spines — Computer Things](https://buttondown.com/hillelwayne/archive/the-llms-yearn-for-the-spines/)

>
