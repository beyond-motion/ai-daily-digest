## 🔥 核心主题：Jev —— "决策模型" 新范式，LLM 变身概率计算器

TypeSafe AI 上周发布 Jev，一个全新类别的模型，被称为 **"System One 模型"**（Simon Willison 认为"决策模型"是更准确的名字）。与普通 LLM 输出文本不同，Jev 接受文本/半结构化数据输入，输出**浮点数**——对应 Yes/No 概率、多选项置信度或评分。其核心理念：

> **"Think of Jev as a frontier-intelligence function call: unstructured state in, typed probabilistic decisions out."**

**关键优势：**
- **极速 + 超低价**：$0.042/百万 token（比 GPT-5 Nano 还便宜），输出完全免费
- **并行问答**：一次传入文档 + N 个问题，全部并行计算
- 三类问题：Noul（Yes/No 伯努利概率）、Choice（多选项置信度分布）、Score（评分量表）
- 适合场景：垃圾邮件检测、搜索重排序、优先级排名、分类标签

**黑盒风险**：只返回浮点数，无法追溯决策依据，偏见问题可能被隐藏。Simon Willison 实验发现它在"好城市"评估中给了 Cupertino 最高分、East Palo Alto 最低分——值得警惕。

**社区创意用法**：
- `jevchat`：让 Jev 玩 2048 游戏
- `jev-leftpad`：用决策模型实现字符串填充
- 搜索重排序：BM25 召回 100 条 → Jev 打分精选

**来源：** [Simon Willison's Weblog](https://simonwillison.net/2026/Sep/21/jev/)

## 🛠️ 工程实践：用 AI Agent 写 Rust，性能超 SOTA 2-20 倍

Max Woolf（minimaxir）分享了一套完整的 **agentic iteration 流水线**，核心发现：

**方法论**：
1. 初始 prompt 让 Agent 用 criterion 建立 benchmark 基线
2. 迭代优化：**"所有 CPU benchmark 至少快 1.2x"** 作为 pass/fail 目标
3. 约束：不许用 `unsafe`、不许并行跑 benchmark、不许用 `target-cpu=native`
4. Agent 每次迭代叠加 1.5-2.0x 提速，多轮下来累计 **2x-20x**

**突破策略**：
- 鼓励用子 Agent（7-12 个 GPT-5.6 Luna 独立探索不同假设）
- "c'mon, try doing a breakthrough" 激将法 → 额外 1.2-1.5x
- 禁止"只调超参数" → 迫使模型寻找根本性重实现
- 竞争模式：让 Agent 写对比基准超越 askama/minijinja/tera

**已验证项目**：UMAP 降维（4x-15x faster + 质量持平）、GBDT、MLP、图网络、模板引擎（比 minijinja 快 2x）、ASCII 渲染（<1ms）、词云生成（10-20ms in WASM）

**核心洞察**：对于机器学习这类有 ground truth 的任务，"先生成快的，再修正确保质量" 比传统"先生成正确的"更高效。

## 🔌 MCP 从未是坏主意：Simon Willison 为其辩护

针对"Hacker News 上 MCP 是否已过时"的讨论，Simon Willison 回应：

**MCP 真正解决的四个问题**（全栈 terminal agent 看不到这些）：
1. **精确控制** Agent 能访问哪些外部服务
2. **安全认证**：不让 Agent 直接持有 API key
3. **用户友好 UI**：让用户自己连接和认证额外服务
4. **审计日志**：记录 Agent 每次操作

> "MCP is obsolete because full coding agents don't need it" — 这种看法忽略了 MCP 的核心用户是**受限型 Agent**，而非 YOLO 全能型 Agent。
